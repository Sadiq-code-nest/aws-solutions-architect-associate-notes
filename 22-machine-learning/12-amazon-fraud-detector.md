# Amazon Fraud Detector 🚨

**What it is:**

A service that uses **machine learning to identify potentially fraudulent activities**.

Think:

> **Fraud Detector = Detect suspicious transactions**
> 

### Example

An online store receives:

```
Customer → $5,000 purchase
```

Fraud Detector analyzes signals such as:

```
Transaction information
User behavior
IP/device information
Historical patterns
```

and produces a fraud risk assessment.

```
Transaction
     ↓
Amazon Fraud Detector
     ↓
Risk assessment
     ↓
Potential fraud 🚨
```

The application can then:

```
High risk → Block / review
Low risk  → Approve
```

**Exam keyword:**

👉 **Detect online fraud using ML**
