# Lambda@Edge vs CloudFront Functions

Another important SAA concept.

You should know both.

### CloudFront Functions

Very lightweight edge logic.

Good for things like:

- Simple URL manipulation
- Header manipulation
- Redirects
- Cache-key manipulation
- Very lightweight request/response processing

### Lambda@Edge

More powerful edge compute.

Useful for more complex logic such as:

- Authentication/authorization logic
- Request transformation
- Response transformation
- More advanced processing

For this question:

> **Authentication process**
> 

→ **Lambda@Edge**
