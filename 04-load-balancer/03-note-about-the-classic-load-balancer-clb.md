# Note About the Classic Load Balancer (CLB)

### Classic Load Balancer (CLB) — v1 ⚠️ Deprecated/Legacy

| Feature | CLB |
| --- | --- |
| Generation | **v1 / Legacy** |
| Layer | **L4 + L7** |
| Protocols | TCP, HTTP, HTTPS, SSL |
| Health checks | TCP or HTTP |
| DNS | `xxx.region.elb.amazonaws.com` |
| Use today? | ❌ **Not recommended for new applications** |
| Replacement | **ALB** for HTTP/HTTPS, **NLB** for TCP/UDP |

**Exam memory:**

> **CLB = old/legacy → ALB/NLB are preferred.**
>
