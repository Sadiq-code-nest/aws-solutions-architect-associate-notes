# Real Exam Scenarios

### Scenario 1

**A company has 500 Windows employees using Active Directory and shared folders. They migrate to AWS without changing applications.**

✅ **Answer:** FSx for Windows File Server

---

### Scenario 2

**A genomics research lab trains ML models on petabytes of data stored in Amazon S3. They need extremely high throughput and low latency.**

✅ **Answer:** FSx for Lustre (integrated with S3)

---

### Scenario 3

**An enterprise already uses NetApp ONTAP on-premises and wants snapshots, deduplication, SMB, NFS, and iSCSI in AWS.**

✅ **Answer:** FSx for NetApp ONTAP

---

### Scenario 4

**A software company runs Linux applications built on ZFS and wants to migrate to AWS with minimal changes.**

✅ **Answer:** FSx for OpenZFS

---

### Scenario 5

**A video rendering farm needs a temporary, extremely fast shared file system. If the storage is lost after rendering, that's acceptable.**

✅ **Answer:** FSx for Lustre **Scratch** File System

---

### Scenario 6

**A financial simulation runs for weeks and cannot lose intermediate data if a file server fails.**

✅ **Answer:** FSx for Lustre **Persistent** File System

# 🎯 Ultimate Memory Trick

Think of **Amazon FSx as a hotel with four specialized rooms**:

- 🪟 **FSx for Windows** = A **Windows office** with SMB, NTFS, and Active Directory. Perfect for company shared folders.
- 🚀 **FSx for Lustre** = A **Formula 1 race track** built for extreme speed—ideal for HPC, ML, and video rendering, especially with S3.
- 🏢 **FSx for NetApp ONTAP** = A **full enterprise storage system** with advanced features like snapshots, deduplication, SMB/NFS/iSCSI, and instant clones.
- 🐧 **FSx for OpenZFS** = A **high-performance Linux/ZFS environment** with snapshots and low latency for existing ZFS workloads.

**One final rule for the exam:**

- **Windows users → FSx Windows**
- **Super-fast computing + S3 → FSx Lustre**
- **Existing NetApp environment → FSx NetApp ONTAP**
- **Existing ZFS environment → FSx OpenZFS**
