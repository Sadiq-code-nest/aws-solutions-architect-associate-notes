# Real Exam Scenarios

### Scenario 1

**A company wants employees to access files through SMB/NFS, but all files should be stored in Amazon S3.**

✅ **Answer:** S3 File Gateway

---

### Scenario 2

**A branch office uses Amazon FSx for Windows File Server and wants faster access with a local cache.**

✅ **Answer:** FSx File Gateway

---

### Scenario 3

**An on-premises database requires iSCSI block storage with cloud-backed snapshots for disaster recovery.**

✅ **Answer:** Volume Gateway

---

### Scenario 4

**A bank has existing tape backup software and wants to move backups to AWS without changing the backup process.**

✅ **Answer:** Tape Gateway

---

### Scenario 5

**A company has no VMware, Hyper-V, or KVM environment but still wants to use Storage Gateway.**

✅ **Answer:** AWS Storage Gateway Hardware Appliance

---

# 🎯 Ultimate Memory Trick

Imagine AWS Storage Gateway as a **universal translator** between your on-premises servers and AWS:

- 📁 **S3 File Gateway** = "My applications speak **files** (SMB/NFS), but AWS speaks **S3 objects**."
- 🪟 **FSx File Gateway** = "My branch office needs a **fast local cache** for **Amazon FSx for Windows**."
- 💽 **Volume Gateway** = "My application thinks it has a **local disk** (iSCSI block storage), but backups/snapshots go to AWS."
- 📼 **Tape Gateway** = "My old backup software still writes to **tape**, but the tapes are actually stored virtually in **Amazon S3 and Glacier**."

### 10-Second Exam Rule

- **Need file share → File Gateway**
- **Need Windows FSx → FSx File Gateway**
- **Need block storage → Volume Gateway**
- **Need virtual tapes → Tape Gateway**
