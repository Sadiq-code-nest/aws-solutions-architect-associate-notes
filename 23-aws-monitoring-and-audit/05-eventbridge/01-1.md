# 🔔 AWS EventBridge — Complete, Clear, Exam-Ready Guide (SAA-C03)

---

# 🧩 1. BIG PICTURE (Understand This First)

👉 **Amazon EventBridge = “Event Router for AWS”**

- Takes **events from sources**
- Applies **rules (filters)**
- Sends to **targets (actions)**

---

## 🧠 Core Idea

> **EventBridge = IF this happens → THEN do that**
> 

---

# 🔍 2. How It Works (Flow)

---

## 🔁 Flow:

1. **Event Source** → generates event
2. **Event Bus** → receives event
3. **Rule** → filters event
4. **Target** → action happens

---

# 📦 3. Event Sources (Where events come from)

---

## 🔹 AWS Services (MOST COMMON)

- EC2 state change
- S3 object upload
- CodePipeline events

---

## 🔹 Custom Applications

- Your app sends events via API

---

## 🔹 SaaS / Partner Apps

- e.g., Shopify, Datadog

---

## 🧠 Exam Tip

👉 If AWS service triggers something automatically → **EventBridge likely used**

---

# 📬 4. Event Bus (VERY IMPORTANT)

---

## Types of Event Buses:

### 1️⃣ Default Bus

- Receives AWS service events
- Always exists

---

### 2️⃣ Custom Bus

- For your own applications

---

### 3️⃣ Partner Bus

- For SaaS integrations

---

## 🧠 Memory Trick

> Default = AWS
> 
> 
> Custom = Your app
> 
> Partner = External apps
> 

---

# 🎯 5. Rules (CORE LOGIC)

---

## What Rules Do:

- Match events using **event patterns**
- Route to **targets**

---

## Example Rule:

👉 IF:

- EC2 state = “stopped”

👉 THEN:

- Send notification (SNS)

---

## 🎯 Filtering

- Based on:
    - Source
    - Event type
    - Detail values

---

## 🧠 Exam Tip

👉 Rules = **filter + trigger**

---

# 🎯 6. Targets (What happens next)

---

## Common Targets:

- AWS Lambda
- SNS
- SQS
- Step Functions
- EC2 (run command)

---

## 🧠 Memory Trick

> Target = Action
> 

---

# ⚡ 7. Event Patterns vs Schedule

---

## 🔹 Event Pattern (Reactive)

👉 Trigger when event happens

Example:

- EC2 stops → trigger Lambda

---

## 🔹 Schedule (CRON)

👉 Time-based trigger

Example:

- Every day at 9 AM

---

## 🧠 Exam Tip

👉 Scheduled jobs → EventBridge (not CloudWatch Events anymore)

---

# 🔁 8. EventBridge vs CloudWatch Events

---

👉 **EventBridge = newer version of CloudWatch Events**

---

## Differences:

- Supports SaaS apps
- More advanced filtering
- Schema registry

---

# ⚖️ 15. Comparison (VERY IMPORTANT)

---

## 🆚 EventBridge vs SNS vs SQS

| Feature | EventBridge | SNS | SQS |
| --- | --- | --- | --- |
| Type | Event router | Pub/Sub | Queue |
| Filtering | Advanced | Basic | ❌ |
| Targets | Many | Subscribers | Consumers |
| Use case | Automation | Notifications | Decoupling |

---

## 🧠 Shortcut

- Complex routing → EventBridge
- Broadcast → SNS
- Buffering → SQS
