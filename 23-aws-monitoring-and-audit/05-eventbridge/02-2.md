# 🧬 1. Schema Registry (Understand Clearly)

## 🧠 What is it?

👉 **Schema Registry = Structure/Blueprint of Events**

- Defines **how event data looks**
- Helps developers **understand & use events easily**

---

## 📦 Example Event

```json
{
  "source": "aws.ec2",
  "detail": {
    "instance-id": "i-123456",
    "state": "stopped"
  }
}
```

👉 Schema = format of this data

---

## 🎯 Why It’s Useful

- Auto-generates code bindings (Java, Python, etc.)
- Avoids guessing event structure
- Improves developer productivity

---

## 🔍 Types of Schemas

- AWS service schemas (auto-discovered)
- Custom application schemas
- Partner schemas

---

## 🧠 Memory Trick

> Schema Registry = **Event “template” library**
>

## 🧠 What is Event Replay?

👉 **Replay = Re-send past events**

---

## 🔁 How It Works

1. Store events in **EventBridge Archive**
2. Later → Replay them
3. Send again to **rules + targets**

---

## 🎯 Use Cases

- Debugging failures
- Reprocessing data
- Fixing bugs and re-running workflows

---

## 🧠 Example

👉 Your Lambda failed yesterday

👉 Fix code

👉 Replay events → process again

---

## ⚠️ Exam Tip

> Replay works ONLY if events were **archived**
>

# 🔐 3. Resource-Based Policy (CRITICAL)

---

## 🧠 What is it?

👉 Policy attached to **EventBridge resource (event bus)**

- Controls **who can send events**
- Controls **who can access the bus**

---

## 📌 Where Applied?

- Event Bus (main use case)

---

## 🎯 Purpose

- Allow cross-account access
- Allow services/apps to put events

---

## 🔁 Example

👉 Account A wants to send events to Account B

- Account B adds **resource-based policy**
- Allows Account A to put events

---

## 🧠 Memory Trick

> Resource Policy = “Who can send events TO me”
> 

---

# ⚖️ 4. IAM vs Resource-Based Policy

| Feature | IAM Policy | Resource Policy |
| --- | --- | --- |
| Attached to | User/Role | Resource (Event Bus) |
| Controls | What you can do | Who can access resource |
| Cross-account | Complex | Easy |

---

## 🧠 Shortcut

- IAM → **You → AWS**
- Resource Policy → **Others → Your AWS**

---
