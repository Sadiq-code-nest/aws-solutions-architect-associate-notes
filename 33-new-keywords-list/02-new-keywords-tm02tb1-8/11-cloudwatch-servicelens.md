# CloudWatch ServiceLens

**ServiceLens** combines **CloudWatch monitoring + X-Ray tracing** to give you an overall view of application health and performance.

Example:

```
CloudWatch Metrics
       +
CloudWatch Logs
       +
X-Ray Traces
       ↓
   ServiceLens
```

It helps you understand:

> **"Which service is causing my application problem?"**
> 

**Think:**

👉 **ServiceLens = Connect metrics, logs, and traces to troubleshoot applications**
