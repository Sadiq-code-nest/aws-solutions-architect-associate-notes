# AWS Direct Connect SiteLink

**AWS Direct Connect SiteLink** is a feature of Direct Connect that allows traffic to be routed between Direct Connect locations using the AWS global network.

Conceptually:

```
On-premises Location A
        ↓
Direct Connect
        ↓
AWS network
        ↓
Direct Connect
        ↓
On-premises Location B
```

It's useful for connecting **on-premises networks/sites**.
