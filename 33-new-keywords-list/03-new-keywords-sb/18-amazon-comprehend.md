# Amazon Comprehend

### Definition

Amazon Comprehend is an NLP service that uses machine learning to analyze text—for example, sentiment, entities, key phrases, and language.


### Why it's irrelevant

It isn't a system-monitoring or EC2 autoscaling service.
