# AWS ParallelCluster

AWS ParallelCluster is used to create and manage **HPC clusters**.

Typical use cases include:

```
Scientific computing
Engineering simulations
HPC workloads
Batch computational workloads
```

AWS ParallelCluster is an **open-source cluster management tool** for HPC.

It helps automatically create HPC environments.

It can configure:

- VPC
- Subnets
- EC2 instances
- Cluster configuration
- EFA

### Think:

> **ParallelCluster = Build my HPC cluster for me**
>
