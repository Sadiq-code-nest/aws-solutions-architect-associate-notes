# AWS Transform & AWS MGN (Q63)

## AWS Transform & AWS MGN — Short Notes

### 1. AWS Transform

**AWS Transform** is AWS's service/tooling for helping organizations **modernize and transform applications and infrastructure**, including migration and modernization tasks.

Think:

> **AWS Transform = helps automate/accelerate migration and modernization.**
> 

---

### 2. AWS MGN

**AWS Application Migration Service (MGN)** helps you **migrate physical servers, virtual machines, and other workloads to AWS with minimal changes**.

Think:

> **MGN = Lift-and-shift servers to AWS.**
> 

Example:

```
On-premises
Windows Server
      ↓
   AWS MGN
      ↓
EC2 in AWS
```

It continuously replicates the source server and helps you launch it as an EC2 instance.

**Exam keyword:**

👉 **Lift-and-shift / rehost / minimal application changes**
