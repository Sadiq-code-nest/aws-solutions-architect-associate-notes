# Short

AWS SAM is an infrastructure-as-code framework for building and deploying serverless applications.

It commonly works with:

- Lambda
- API Gateway
- DynamoDB
- Step Functions
- etc.

Example:

```
SAM template
     ↓
Lambda
     ↓
API Gateway
```

But SAM isn't a performance solution by itself.

It's a **deployment/development framework**.

So don't see:

> "SAM"
> 

and think:

> "faster application."
>
