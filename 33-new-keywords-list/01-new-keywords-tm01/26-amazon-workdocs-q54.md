# Amazon WorkDocs (Q54)

### Amazon WorkDocs

**Amazon WorkDocs** is a **secure, managed document storage and collaboration service** from AWS.

Think:

> **WorkDocs = Google Drive / Microsoft OneDrive for organizations, managed by AWS.**
> 

### Simple scenario

A company has:

```
Employees
   ↓
Amazon WorkDocs
   ├── Company policies
   ├── Project documents
   ├── PDFs
   └── Reports
```

Employees can **store, share, edit, and collaborate on documents** securely.

### AWS SAA-C03 shortcut

**WorkDocs → Enterprise document storage + sharing + collaboration**

Don't confuse it with:

- **S3** → Object storage for applications/data
- **EFS** → Shared Linux file system
- **WorkDocs** → Human users collaborating on documents
